# Language Translation Tool

An easy-to-use web-based language translation tool created with **Python**, **Streamlit**, and **Deep-Translator** (Google Translate API engine).

## Features
- **Language Detection:** Option to auto-detect source language.
- **Multiple Languages:** Translates text across major world languages.
- **Clean UI:** Built with Streamlit for a fast and clean user experience.
- **Copy Text:** Easy code container view to quick-copy translated outputs.

## Setup & Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/language-translation-tool.git
   cd language-translation-tool
   ```

2. **Install dependencies:**
   ```bash
   pip install streamlit deep-translator
   ```

3. **Run the Application:**
   ```bash
   streamlit run app.py
   ```
